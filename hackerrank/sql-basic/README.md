# HackerRank SQL Practice – Basic SELECT

This folder contains my solutions to beginner SQL exercises from HackerRank.

The exercises focus on basic SQL queries using simple `SELECT` statements, filtering data with `WHERE`, removing duplicates with `DISTINCT`, sorting results, and using basic aggregate functions.

## What I Practiced

- Selecting all columns with `SELECT *`
- Selecting specific columns
- Filtering rows with `WHERE`
- Using multiple conditions with `AND`
- Removing duplicates with `DISTINCT`
- Working with modulo `%`
- Counting rows with `COUNT()`
- Counting unique values with `COUNT(DISTINCT)`
- Sorting results with `ORDER BY`
- Limiting results with `LIMIT`
- Checking string length with `LENGTH()`

## Purpose

The purpose of this folder is to practice basic SQL syntax and build confidence with simple database queries.

These exercises are part of my SQL learning journey and preparation for QA-related work.
