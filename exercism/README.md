# Exercism SQLite Practice

This folder contains my SQLite practice exercises completed on Exercism.

I use these exercises to improve my SQL basics, practice writing queries, and build confidence with relational databases.

## What I practice here

* Basic `SELECT` queries
* Filtering data with `WHERE`
* Sorting results with `ORDER BY`
* Working with multiple tables
* `INNER JOIN` and `LEFT JOIN`
* Basic aggregate functions
* Simple problem solving with SQL

## Why SQLite?

SQLite is a lightweight database that is useful for learning and practicing SQL fundamentals.

The main goal of this folder is not to focus on one specific database system, but to practice core SQL concepts that are useful across different relational databases.

## Platform

Exercises are completed on Exercism:

* Track: SQLite
* Focus: SQL fundamentals and query practice

The purpose of this folder is to document my SQL learning progress and keep my practice exercises organized.
