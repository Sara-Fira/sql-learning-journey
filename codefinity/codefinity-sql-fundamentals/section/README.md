# SQL Fundamentals

This folder contains my exercises from the Codefinity SQL Fundamentals course.

## Topics covered

* Retrieving data with `SELECT`
* Selecting individual, multiple, and all columns
* Using `DISTINCT`
* Limiting query results
* Sorting data with `ORDER BY`
* Filtering data with `WHERE`
* Using comparison and logical operators
* Checking ranges and `NULL` values
* Working with aggregate functions: `AVG`, `COUNT`, `MAX`, `MIN`, and `SUM`

## Practice

The course included guided exercises and challenges focused on retrieving, sorting, filtering, and analyzing data from tables.
