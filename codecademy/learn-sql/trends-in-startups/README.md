# Trends in Startups

A beginner SQL project from Codecademy.

## Description

This project uses a `startups` table containing information about startup companies.

The goal of the project was to analyze startup data and find useful insights about company valuations, funding, categories, locations, and number of employees.

## What I practiced

* `SELECT`
* `FROM`
* Aggregate functions
* `COUNT()`
* `SUM()`
* `MAX()`
* `MIN()`
* `AVG()`
* `ROUND()`
* `GROUP BY`
* `HAVING`
* `ORDER BY`
* Filtering grouped results

## Example tasks

In this project, I practiced writing queries to:

* count the total number of companies,
* calculate the total valuation of all startups,
* find the highest amount of money raised,
* find the oldest company by founding year,
* calculate average valuations,
* group results by category,
* round average values,
* sort categories by average valuation,
* count companies in each category,
* filter categories with more than three companies,
* calculate average startup size by location,
* filter locations with average company size above 500 employees.

## Main lesson

Aggregate functions are useful for summarizing data.

`GROUP BY` allows data to be grouped by category or location, while `HAVING` is used to filter grouped results.
