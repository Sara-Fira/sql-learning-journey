# New York Restaurants

A beginner SQL project from Codecademy.

## Description

This project uses a table called `nomnom`, which contains information about restaurants in New York City.

The goal of the project was to write SQL queries to explore the data and find restaurants based on different conditions, such as cuisine type, neighborhood, reviews, price, and health grade.

## What I practiced

* `SELECT`
* `FROM`
* `WHERE`
* `DISTINCT`
* Filtering data
* Using comparison operators
* Using `AND` and `OR`
* Searching text with `LIKE`
* Finding empty values with `IS NULL`
* Sorting results with `ORDER BY`
* Limiting results with `LIMIT`
* Using `CASE` statements

## Example tasks

In this project, I practiced writing queries to:

* view all restaurant data,
* find distinct neighborhoods and cuisines,
* filter restaurants by cuisine type,
* find highly rated restaurants,
* search for restaurants by name,
* find restaurants in selected neighborhoods,
* create a Top 10 ranking,
* classify restaurants using a custom rating system.
