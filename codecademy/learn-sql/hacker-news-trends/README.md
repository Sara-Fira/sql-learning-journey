# Hacker News Trends

A SQL practice project based on a Hacker News dataset.

## Description

This project explores Hacker News stories using SQL queries.
The goal was to analyze story scores, users, sources, and posting times.

## Technologies

* SQL
* SQLite

## What I Practiced

* `SELECT`
* `ORDER BY`
* `LIMIT`
* Aggregate functions
* `GROUP BY`
* `HAVING`
* `CASE`
* `LIKE`
* `strftime()`

## Example Queries

The queries check:

* Top stories by score
* Total score of all stories
* Users with high total scores
* Story sources such as GitHub, Medium, and New York Times
* Average score by posting hour

## Purpose

The purpose of this project was to practice SQL data analysis using real-world style data.
