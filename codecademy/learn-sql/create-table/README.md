# Create a Table

This is a beginner SQL project from Codecademy.

## Project Description

In this project, I created a simple `friends` table and practiced basic SQL commands for working with data.

## What I Practiced

* Creating a table with `CREATE TABLE`
* Adding rows with `INSERT INTO`
* Viewing data with `SELECT`
* Updating existing records with `UPDATE`
* Adding a new column with `ALTER TABLE`
* Deleting rows with `DELETE`

## Table Structure

The table contains the following columns:

* `id`
* `name`
* `birthday`
* `email`

## Final Result

At the end of the project, the table contains two friends with their names, birthdays, and email addresses.
